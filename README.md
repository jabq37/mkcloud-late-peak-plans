## 晚高峰为什么会卡，专线凭什么不一样

晚上七八点到十一点是国内用网峰值。普通 VPS 的流量要挤国际出口，机场节点的流量则要挤更多用户共享的同一批线路——中转机房带宽就那么大，人一多，延迟飙高、丢包率上升，这就是“晚高峰爆炸”的来源。有讨论搬瓦工这类 VPS 的文章贴过 24 小时 ping 监控：白天 100ms 出头，晚上直接飙到 200ms 以上。

mkcloud 的思路是物理上避开这场拥堵。它提供的几类产品分别是：

- **IEPL（以太网专线）**：点对点独享电路，代表线路是广港，广州入口到香港出口，官网标端内参考延迟 1~2ms；
- **IPLC（国际私有租用线路）**：沪日、沪美、沪港方向，端内参考延迟沪日约 25~28ms、沪美约 124~134ms；
- **IX 上云互联优化专线**：经阿里云、腾讯云、百度云等云厂内网接入，深港方向端内参考 1~2ms，不需要公网跑跨境段。

关键词是“端内”。官网知识库反复强调：1~2ms 或 25~28ms 指的是入口到出口这段专线的延迟，不包括你本地到入口、出口到最终平台的耗时。这个口径比较诚实，也提醒了一点——专线解决的是跨境段拥塞，你家里宽带本身的晚高峰拥堵它管不了。

另外要知道，独享带宽产品是“任何时候都是这个速率”，共享流量款标的是峰值带宽，官网明确说明“共享带宽为峰值，不保证持续跑满”。这一点后面选套餐时会用到。

## 几个高频问题

**专线 VPS 和机场节点的区别到底是什么？** 机场是多人共享的中转服务，专线 VPS 交付的是一台带独立入口 IP 和独立出口 IP 的云服务器，走的是独享或按套餐划分的专用电路。前者用途灵活但晚高峰受罪，后者贵但稳定，且 mkcloud 这类服务商明确禁止把专线当机场用。

**月流量超了会怎样？** 当前规则是按上行、下行双向统计，达到额度后暂停，可以自助购买流量重置，或者提交工单补差价升级。所以选档时建议按实际用量的 1.2 倍左右留余量。

**能当建站服务器用吗？** 不行。出口不接受外部连入，不能作为公开源站、支付回调地址或游戏服务端，这是产品页写明的使用边界。

**IPv6 支持吗？** 官方知识库的说法是现有资料不足以确认所有套餐的 IPv6 支持，业务必需的话下单前找客服确认，别默认双栈。

**值不值？** 单看数字，198 元/月买个 1 核 2G 的 VPS 确实比搬瓦工贵不少。但你买的不是那台 VPS，是它背后那条不随晚高峰波动的跨境通道，外加双独立 IP。如果你的业务收入依赖晚上那几个小时的网络稳定，这笔账其实不难算；反过来，只是偶尔查查资料，普通 VPS 便宜得多，没必要为用不上的稳定性付钱。
